第1回 WWW と HTML

HTMLの初歩的なページ編集

<p>や<strong>などのページを作る際の基本となる文書を学んだ。 HTML文書は基本的にタグで囲んでその中に必要に応じて入れ子を入れるなどがある。 そして最も重要なのが終わりのタグには/（スラッシュ）をつけなければいけないことである。

HTML文書の構成は以下のようなテンプレートからなる。 

<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>？？？</title>
  </head>
  <body>
    <p>？？？</p>
  </body>
</html>

<title></title> と <p></p> の間に文字を入れたり、 <p></p> の中に <strong></strong> を入れることができる。

加えて、同じファイル内にある別のHTML文書をハイパーリンクとして載せることもできるようになった。 ファイル外のものを指定する際には手順が異なるため、注意が必要であると感じた。

演習の成果： 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

CSSの使用によって味気ないページを可能な限り色付けることができるようになった。第一回目で習ったHTMLは文字だけに特化したものだが、CSSは色などに特化したものだと言える。グラデーションや文字サイズ、フォントなどかなり幅広いものまで作り変えることができるためやることが一気に広がったとも言える。こだわり出したらキリがないため、ある程度の方向性を持たせて色合いなどを調整すればよりおしゃれなものが作り上げることができる。

演習の成果： 演習2-3:ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本
