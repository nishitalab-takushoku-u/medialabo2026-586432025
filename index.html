各授業回の学習事項

第1回 WWW と HTML

HTMLの初歩的なページ編集

<p>や<strong>などのページを作る際の基本となる文書を学んだ。 HTML文書は基本的にタグで囲んでその中に必要に応じて入れ子を入れるなどがある。 そして最も重要なのが終わりのタグには/（スラッシュ）をつけなければいけないことである。

HTML文書の構成は以下のようなテンプレートからなる。 

<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>？？？</title>
  </head>
  <body>
    <p>？？？</p>
  </body>
</html>

<title></title> と <p></p> の間に文字を入れたり、 <p></p> の中に <strong></strong> を入れることができる。

加えて、同じファイル内にある別のHTML文書をハイパーリンクとして載せることもできるようになった。 ファイル外のものを指定する際には手順が異なるため、注意が必要であると感じた。

演習の成果： 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

CSSの使用によって味気ないページを可能な限り色付けることができるようになった。第一回目で習ったHTMLは文字だけに特化したものだが、CSSは色などに特化したものだと言える。グラデーションや文字サイズ、フォントなどかなり幅広いものまで作り変えることができるためやることが一気に広がったとも言える。こだわり出したらキリがないため、ある程度の方向性を持たせて色合いなどを調整すればよりおしゃれなものが作り上げることができる。

演習の成果： 演習2-3:ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

JSの活用によってコンソールを介して様々なことを行えるようになった。開発ツールのコンソールはそれ単体でJavaでやっていたプログラミングに近いことができる。それだけではなくJavaよりも単純なコードで動くため使い勝手も良く。簡単な命令であれば計算なども行えるほどである。今回やったところはその初歩的な部分としてある命令を実行するとそれに従ってあらかじめJavaスプリクトで組んだコードどうりに表示されるというもの、Javaに似て非なるものなので個人的に勉強する機会は多くする必要がある。

演習の成果： 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

前回やったJavaScriptの応用になる。前回は基本的な処理だけをやっていたが、今回では実際にサイト上で押せるボタンや入力用のテキスト欄などを設置できるようになり、あらかじめ決められていた値などつけたりすることで、ボタンひとつでさまざまなことができるようになった。数合わせ、足し算などもでき。Java系列であるからか構文というか仕様が少し似通っている点が見受けられるためJavaの復習をしておくのも今後円滑な習得をするうえで必要なのかもしれないと学べた。

第5回 イベント処理

DOMの二回目の学習ではHTMLの要素を新しく作成したり、逆に要素を削除できるようになった。基本的に全てHTML内の作業で事足りてしまうので使い所は今ひとつだと感じる。しかし前回のボタンを利用して出現させる方法と組み合わせることによってサイト内のボタンを一つ押すことによって瞬時に出現させるなどの芸当ができるため、DOMを使ったHTMLの新規作成はボタンを利用する際にはかなり頻繁に使うことがあるだろう。変わらず前回と同じでよく使う文法などは頭に入れておく必要がある

第6回 工夫点、苦心点、強調点、感想

　全体を通して言えることはjavaとjava scriptはどこか違う点などがあり最初のうちはプログラミングの勘を思い出すという意味でもとても苦労しました。加えて、HTMLをいじっている時まではまだ簡単なようにも思えていたのですがDOMに入ってから難易度が飛躍的に上昇したなとと思い、毎回課題に取り組み続けるたびに自分の中にしっかり定着しているのかどうかと少し疑心暗鬼で不安にもなりながらやっていました。ですがこの第6回目を迎える頃には自分が何をやっているのか、どいういうことが必要なのかというのを自分自身で分かるようになっていたと思います。特に理解に苦しんだところはDOMの要素の追加や探索からその役割を入れるという流れでした、最初は話を聞いていても何をやっているのかがわからなすぎていざ自分で実践してみることには、何をやっていたんだっけ？という状況になることが多かったです。また先生が説明した通りにコピーアンドペーストしている時も本当自分は理解していうのか？という気持ちは湧き上がっていました。ですがこういう類のものはほとんど反復練習があってこそ身につくものなので最終的には完全な理解に向かうためには何はともあれ理屈を理解しつつ手を動かして覚えるのが一番手っ取り早く身につくことができる手法なのだと感じました。

　プロジェクト課題では、たて並ぶ文章の中で一見するだけで気温を確認できるようにバックラウンドをつかしました。それぞれ最低気温には水色、最高気温には薄赤色といった具合に配色いたしましたまた他にも湿度の部分には青色を使いました。大きな点は天気が一目で分かるように写真を用いている点です、本来なら天気に当たる部分をバックラウンドを使った配色で天気に応じて色を変えようと考えていたのですが、それだと他の最低気温、最高気温、湿度の部分と色が被ってしまうという理由から写真を用いるわかりやすいものにしました。世界の天気の隣には四つの状態の天気写真を載せることによって、見た人がこの四つの天気がから表示されるということを暗喩する形で出しました。最終的にプロジェクト課題のところはシンプルな作りにしました、個人的にもう少し豪華にしてもいいのではとは思ったのですが、豪華にしすぎて情報が一見しただけではわかりずらい作りになってしまったらそれこそ本末転倒になってしまうのでやめておきました、シンプルで味気ないと思っているデザインこそ個人的には一番見やすかったりわかりやすかったりするデザインだと感じているので、この点だけは譲らないように作ったつもりです。
